# Домашнее Задание по Анализу выживаемости

Создайте проект и добавьте в него файлы `homework-data.qmd` и `homework-analysis.qmd`.

Сначала выполните `homework-data.qmd`.
В этом файле необходимо сгенерировать синтетический набор данных, который будет использоваться в дальнейшем анализе.
Сохраните полученный датасет в формате CSV под названием `data.csv` в папке проекта.

Далее в `homework-analysis.qmd` загрузите полученные данные и выполните задания.
При необходимости можно создавать дополнительные чанки.

Для анализа выживаемости используйте пакет `survival`.
Для построения кривых Каплана–Мейера – базовый `plot()` или пакет `ggsurvfit` (предпочтительно).
Для таблиц базовые функции `summary`, пакет `flextable` или пакет `gtsummary`.

Соберите `homework-analysis.qmd` в HTML и загрузите проект в личный репозиторий GitHub.
В репозитории должны быть: заполненные `homework-data.qmd`, `homework-analysis.qmd`, сгенерированные `data.csv` и итоговый `homework-analysis.html`.
Приложите ссылку на репозиторий.

Обратите внимание!
Оформление графиков и таблиц также будет оцениваться: они должны быть читаемыми, иметь понятные подписи осей, заголовки и легенды.
Не забывайте сопровождать полученные результаты краткими интерпретациями и выводами.
